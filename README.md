# JOURYVEL — Luxury 7-Day Skincare Program

> *Timeless Scents · Modern Luxury*

Interactive swipeable 7-day skincare program with the JOURYVEL luxury aesthetic.

## ✨ Features

- 🎴 **Swipeable day cards** — swipe right/left to navigate between days
- ☀️/🌙 **AM/PM tabs** — toggle between morning and evening routines
- 👑 **JOURYVEL luxury design** — navy + gold + Playfair Display
- 📱 **Mobile-first** — works perfectly on iOS/Android
- ⚡ **Pure vanilla JS** — no dependencies, instant load
- 🔄 **Circular navigation** — Sat → ... → Fri → Sat
- 📊 **Progress indicators** — animated gold dots
- 🎨 **4 color themes** — Glycolic (orange), Retinol (purple), Recovery (green), PanOxyl (red)
